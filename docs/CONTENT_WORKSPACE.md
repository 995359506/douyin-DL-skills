# 内容工作台：使用、数据边界与验收

适用入口：本机 `http://127.0.0.1:8080/app/`。本次增加全文搜索、总结与视频联动、句子素材库、专题工作台、批次结果与调用额度，复用已有下载、口播、总结和蒸馏结果。

## 从批次到可使用文稿

1. 提交下载或作者分析任务，在“批次结果与调用额度”选择对应批次。
2. 展开明细，分别检查下载、口播、总结状态，点击“阅读与播放”。
3. 在阅读器核对文本；选中文字收藏，或点击“摘录此段”后调整范围。
4. 在“内容工作台 → 句子素材”补标签、理解和个人改写，加入一个或多个专题。
5. 在专题分组、排序、补笔记，勾选此次采用的资料，预览实际发送范围。
6. 选择要点、结构、角度、提纲或初稿，确认生成；核对当次来源快照后导出 Markdown。

## 全文搜索

- “内容工作台 → 全文搜索”检索标题、作者、原始转写、整理稿、视频总结；原有任务列表搜索仍用于筛选任务。
- 同一视频的多次下载记录和多个命中字段聚合展示，匹配片段分别标明来源；相关度按实际命中次数排序，也可按采集时间排序。
- 空格分隔词是 AND，可以分别命中同一视频的口播和总结；英文双引号内按连续短语匹配，例如 `"沟通表达" 开场`。
- 进行 NFKC 全半角规范化及大小写折叠；标点按字面保留，不当成 FTS 操作符。支持一、二字中文子串；不提供语义搜索。
- 日期筛选使用保存记录中的采集时间，非平台发布时间。没有可确认日期时不编造发布时间。
- 独立蒸馏保存的逐视频资料纳入视频结果；跨视频的博主归纳选择“独立博主蒸馏结果”单独查看，不混成某条视频的原话。
- “神评论灵感”属于 AI 创作，不进入事实正文搜索。
- 搜索、索引和阅读只在本地进行，不额外下载、不上传资料、不调用模型。封面图片仍沿用原有图片地址。
- 查询时检查现有来源，按内容指纹更新索引；新生成、作者变更和删除立即在下一次查询反映。`POST /api/content/index/rebuild` 可重新校对，无需重分析视频。
- 返回搜索结果保留查询、筛选、页码与滚动位置；会话存储不保存完整搜索正文。

## 阅读与视频联动

- 阅读器同时提供本地视频、来源段落和时间线。打开阅读器或搜索结果不自动播放；明确点击可用时间点才跳转并播放。
- 零秒、数值秒、`MM:SS`、`HH:MM:SS` 和常见范围格式兼容；负值、非数值、超出片长等时间不可跳转。
- 模型估计时间显示“约”；新分段总结按原片段起点在代码中换算全片时间，不让合并模型重写时间位置。
- 历史分段结果缺少可靠全片换算依据时禁用跳转，文字仍可读。不会为此自动重新分析历史视频。
- 播放时突出当前时间线；“跟随播放”可主动开启，手动滚动时间线会停止跟随，避免打断阅读。
- 视频缺失或读取失败仍能看、复制、收藏保留文字；关闭阅读器或切换视频会停止旧视频播放。
- 口播目前没有可靠逐句对齐时间，不据此伪造定位。逐句音画联动不在本次实现内。

## 句子素材与删除关系

每条素材保存收藏时文本、最小上下文、来源类型、视频与作者、原链接、来源版本和可用时间。来源类型明确区分“原始转写（未核实）”“AI 整理稿”“AI 总结”“个人笔记”。

- 来源摘录是快照，重新生成口播或总结不会覆盖它；来源更新或删除会显示提示。
- 标题、标签和备注可以修改；“个人改写”单独保存，不能覆盖来源摘录。
- 桌面可选中文字收藏；手机可点击“摘录此段”调整范围后收藏。浏览器 UTF-16 范围兼容表情和组合字符，避免摘录错位。
- 重复收藏同一来源、同一内容范围时提示打开已有素材修改备注，或明确另存一条。
- 素材库可搜索摘录、标题、标签、备注和改写，按作者、标签、来源类型筛选。
- “待看／已看”和“值得重看”是视频阅读标记，与下载及分析状态独立，不自动冒充已读。

| 操作 | 影响 |
| --- | --- |
| 删除本地视频文件 | 播放不可用；仍存在的来源文字、素材、专题快照保留 |
| 删除下载任务 | 沿用现有任务删除行为；当前来源退出搜索，个人素材和专题快照不随任务删除 |
| 删除素材 | 删除素材库该条；已加入专题的快照保留 |
| 从某专题移除 | 只移除该专题引用，原素材及其他专题不变 |
| 删除专题 | 删除该专题、其引用和生成版本；原视频、素材不受影响 |

删除任务不等同于承诺清空所有个人快照；如需清理个人积累，应单独删除相应素材或专题。

## 专题、预览和版本

- 专题按用途组织，可填写名称、目标、说明，并维护分组、顺序、专题备注和个人笔记。
- “加入专题”可从搜索、来源阅读、素材库进入。同一素材加入多个专题时，各专题备注和顺序独立。
- 只加入视频意味着保存引用，不能直接参加文字生成；需明确加入已有口播、总结或素材片段，不触发重新分析。
- 生成前必须勾选资料，可填写用途、受众、语气、篇幅；设置会保留。预览显示此次实际发送的文字、个人备注及改写，不默认发送全库或视频。
- 单次预览内容按序列化资料和设置限制在 6 万字符；超出时要求缩小范围，不静默截断或自动拆成多次付费调用。
- 每次生成保存当次资料快照、设置和新版本，用户编辑稿与模型原稿分开。重新生成不会覆盖旧版本或个人编辑。
- 输出要求区分摘录、归纳和创作，并附 `[S1]` 等来源编号；不存在的编号、检测到的与来源不一致的中文直引会判为失败。没有来源编号时提示待核对，不能把模型输出等同于已核实事实。
- 默认不补外部知识，不把新创作冒充作者原话或用户真实经历。用户仍需核对具体事实和引用。
- 可导出整个专题资料，或某个生成版本；Markdown 带来源信息和当次文本快照，不覆盖现有博主蒸馏文件。

## 批次结果、请求上限和费用

- 下载、口播、总结独立统计：完成、复用、共享执行、待处理、失败、部分完成、暂停、未请求。下载成功而总结失败不会合成“整条成功”。
- 明细可按作者、处理状态筛选，提供阅读与播放、失败阶段重试入口；重试沿用批次额度归属，保留已有成功结果。
- 逻辑分析任务数与实际推理 HTTP POST 次数分开。分段、重试、格式重试、备用通道、合并和归纳的真实请求都占次数；复用已有结果不新增次数。
- 同一运行结果被其他批次共享时只由执行所属批次计费，不向引用批次重复记账。旧任务 ID 的后续重做不改写已冻结的历史批次结局。
- 次数上限在请求发出前原子占额，五个并发总结共同遵守同一批次额度。达到上限后不再启动新模型请求，已完成内容保留，在途请求仍可能完成并产生费用。
- 在批次面板提高上限或选“不设上限”，保存后点击“继续未完成分析”。恢复沿用执行编号和成功阶段检查点，避免重新处理成功片段或已完成转写。
- 专题上限是本专题累计上限，不是每版本重置；新生成确认留空会取消旧上限。暂停版本的“调整上限并继续此版本”保留调整后的额度，恢复原版本及原资料快照。
- 网络超时或重启后结果未知的请求仍保留已占次数，不假装没有发出；台账不可用时停止发新请求。恢复不等于承诺消除上游未知结果的计费。
- 展示上游实际返回的用量；费用只按通道、模型、币种及费率版本估算。缺价格或必要用量显示未知／不完整，不当作零；历史无台账记录的次数和费用保持未知。
- 费率可经 `/api/model-prices` 读取或配置，仅影响后续请求的估算，旧请求保留原费率快照。本版没有金额硬预算，不保证人民币绝不超支。
- 单次网络耗时与剩余时间分开；同类至少 10 个成功逻辑执行样本才给文件已就绪分析的 p10–p90 区间。排队、下载冷却、用户暂停及未就绪下载不混入这个区间；下载缺样本时仍未知。
- 没有无依据的“高价值”推荐或自动全库资料发送。

## 开发入口与回归

内容数据和路由：`skills/douyin_downloader/content_service.py`、`content_api.py`；批次连接：`batch_results.py`、`product_runtime.py`、`batch_results_api.py`；用量：`usage_ledger.py`、`usage_api.py`。内容来源读取不创建隐藏下载任务。

常用 API：`GET /api/content/search`、`GET /api/content/videos/{aweme_id}`、`GET /api/content/sources/{source_id}?revision=...`、素材与专题的 `/api/content/materials`、`/api/content/topics`、`GET /api/batch-results/{kind}/{batch_id}`。模型接口仅在用户明确分析或确认生成时调用。

离线回归命令（主目录执行）：

```sh
.venv/bin/python -m pytest -q
npm --prefix frontend test
npm --prefix frontend run build
.venv/bin/python -m tests.benchmarks.benchmark_content_search --videos 10000 --repeats 3
```

重点验证：标题不命中而口播命中；同视频多字段聚合；中文短词和短语；新旧与独立蒸馏资料；收藏后来源重生成／删除；一素材多专题移除隔离；新版本不覆盖编辑；缺文件仍阅读；零秒及错误时间；旧不可靠分段禁跳；混合下载分析状态；复用零调用；并发占额；暂停恢复同执行；缺费用保持未知；搜索返回状态保留。

## 搜索性能：已测范围和目标

使用临时 SQLite 合成数据，不读写真实业务库。每视频 5 块：标题作者、原始口播、整理稿、总结概览、一个要点；长正文每份 256 字，包含完整来源刷新、指纹校对、中文 AND、视频聚合、分页，不含浏览器渲染。

| 视频／内容块 | 首次建索引并查询 | 暖查询样本 | 暖查询中位 |
| --- | --- | --- | --- |
| 1,000／5,000 | 0.628 秒 | 0.189、0.188 秒 | 0.188 秒 |
| 10,000／50,000 | 6.680 秒 | 2.001、1.948、1.949 秒 | 1.949 秒 |

建议验收目标：当前数百视频规模暖查询 0.5 秒以内；上述合成万视频规模暖查询 3 秒以内、初建 10 秒以内。这些是测试目标，非响应保证；更长正文、磁盘、其他作业及结果大小变化时应按同一脚本重测，不能将这组数字外推到任意资料规模。
